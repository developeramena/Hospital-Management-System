# Hospital Management System

A desktop hospital management application built with Python, Tkinter, and MySQL. It supports patient, doctor, appointment, billing, staff, room, and inventory management.

## Run Locally

```bash
git clone https://github.com/developeramena/Hospital-Management-System.git
cd Hospital-Management-System
pip install -r requirements.txt
python run.py
```

Create the MySQL database using `database/init_database.sql` and configure the connection in `config/database.py` or with environment variables based on `.env.example`.
